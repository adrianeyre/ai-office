# Pen-testing assessments

One assessment per probe issue, against one pinned commit. What an
assessment holds, and the list of them, is in
[the pen-testing index](../README.md#assessments).

Each assessment links every probe test file it committed that holds an
`it.fails`; `pnpm test` fails while one is not linked from a file here
([the cross-reference test](../README.md#the-cross-reference-test)).
