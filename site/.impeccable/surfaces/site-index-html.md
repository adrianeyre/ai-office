# Surface brief: the AI Office website (site/)

Scope: the one-page project website at ai-office.adrianeyre.co.uk, and the README's imagery that reuses its world. Mode: Persuade.
Audience: developers and small teams with AI accounts, evaluating then installing a self-hosted team of Agents.
Action: copy the install command / follow the quick start; secondary: the GitHub repository.
Proof: real app screenshots (docs/images), faithful product demos, the full setup guide. No invented users, stars or benchmarks.
Constraints: keep every fact and section (restructure freely); British English; glossary terms; WCAG 2.2 AA; reduced motion; static Vite build.

## Direction contract

THESIS: The site is the Floor's planning wall. Every issue is a pinned index card that walks needs-work → needs-review → needs-qa → needs-docs → ready-to-merge. Refuses the dark-grid AI-tool hero (split headline + app mock + bento).

OWN-WORLD: Deep teal acoustic felt (#23494d family) as the ground of the whole page; card stock (paper #fbf8f2) carries every word, in ink #23272c; Stage dot stickers and card header strips in the product's Stage colours (work blue, review violet, QA teal, docs magenta); masking-tape zone labels (#ecd9a0); push pins; a rubber-stamp MERGED in state-ok green. STORY: The visitor sees issues move themselves across the wall, understands Floors, Agents, Stages and the Gateway, believes it is real from pinned screenshots, and copies the install command.
